# .github

farfarfun-drive 组织的 Community Health Files 仓库，只承载组织主页，不含可运行代码。

## Usage

[`profile/README.md`](profile/README.md) 会自动渲染到
[组织主页](https://github.com/farfarfun-drive)。要改主页展示的内容，直接编辑该文件并提交。

新增或下线一个驱动包时，记得同步更新 `profile/README.md` 里的「独立驱动包」表格和
「支持的网盘」清单——这两处是手工维护的，不会自动跟随仓库变化。

## 关于 farfarfun-drive

[farfarfun](https://github.com/farfarfun) 的网盘 / 云存储产品线：以
[fundrive](https://github.com/farfarfun-drive/fundrive) 的统一 `BaseDrive` 接口为核心，
配套各网盘的独立驱动包与蓝奏云 SDK / 桌面客户端。
